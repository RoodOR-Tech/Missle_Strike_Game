# Missile Strike

A retro Missile Command–style arcade game in a single HTML file. Tap or click to fire interceptors and protect your cities from incoming missiles.

**Play it:** open `index.html` in a browser, or visit the GitHub Pages site served from `docs/`.

## How to play

- **Tap / click** anywhere to fire an interceptor toward that point — it detonates at the X marker.
- Incoming missiles caught in the blast are destroyed. One blast can chain multiple kills for bonus points (x2, x3, ...).
- Each city destroyed costs a life. Surviving cities earn a bonus at the end of every wave.
- **P** or **Esc** pauses (or tap the ⏸ button). **M** toggles sound (or tap 🔊).

## Features

- Pure HTML5 canvas — no dependencies, works on desktop and mobile
- Procedural sound effects via the Web Audio API
- High score saved locally in your browser
- Combo scoring, screen shake, wave announcements, and floating score popups
